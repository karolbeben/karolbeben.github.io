# Karol Bęben — personal website

Personal website: **[karolbeben.github.io](https://karolbeben.github.io/)**

I am a research engineer working on autonomous UAV systems. My background is in avionics, remote sensing, UAV integration and flight testing. I am now extending that foundation through doctoral research on multi-UAV coordination, simulation and reinforcement learning for low-altitude remote sensing.

The website presents a short introduction to my work, research interests, selected projects, experience, and education. It is currently being updated as I add more project and research details.
